# Stonewards Party HUD

A lightweight, **client-side** party HUD for **Stonewards**. See player names, classes, HP, and downed status at a glance. Includes optional teammate outlines and nameplates, Hunter companion health, and defensive wall HP.

**Only you need the mod** — teammates can play without installing anything.

## Installation

Install [PartyHUD on Thunderstore](https://thunderstore.io/c/stonewards/p/thereisnouser/PartyHUD/) using [r2modman](https://thunderstore.io/c/stonewards/p/ebkr/r2modman/), then launch the game with mods enabled. Required dependencies are installed automatically.
