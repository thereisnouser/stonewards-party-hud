# Stonewards PartyHUD

A lightweight, **client-side** party HUD for Stonewards, styled to match the game's pixel-art interface.

## Features

- **Party status:** player names, classes, HP, and downed state.
- **Teammate tracking:** outlines and nicknames, optionally visible through walls.
- **Extra health:** Hunter's bear, defensive walls, and King HP when available.
- **Host tools:** teammates' ring builds, rarities, pick counts, and connection ping.
- **Built-in settings:** toggle features, adjust HUD size/position, and rebind hotkeys directly in-game. Settings are saved automatically.

## Controls

| Key (default) | Action |
| --- | --- |
| **F7** | Open PartyHUD settings |
| **F8** | Show/hide ring builds (host only) |
| **F9** | Next player in the build inspector |
| **PageUp / PageDown** | Previous / next ring page |

All shortcuts support rebinding, including Ctrl, Shift, and Alt combinations.

## Installation

Install [PartyHUD on Thunderstore](https://thunderstore.io/c/stonewards/p/thereisnouser/PartyHUD/) through r2modman or another compatible manager and launch **modded**. BepInEx is installed as a dependency. **Other players do not need this mod.**

*Ring inspection and ping are host-only; King HP depends on game data availability.*
